# 테스트 시나리오

## 1. 제안서와 견적 요청

- 통화 상황: 대학 교육 담당자가 비전공자 대상 AX 과정안과 20명 기준 견적을 요청한다. 예산은 미확정이다.
- 기대 요약: 관심 대상, 인원, 자료 요청과 예산 불확실성이 함께 표시된다.
- 기대 영업 단계: `제안서 요청`
- 기대 업무: 맞춤형 교육과정 제안서, 견적서, 예산 항목 확인, 3일 후 후속 통화
- 동적 업무 확인: `예산 집행 가능 항목 확인 요청`이 데이터에서 카드로 표시된다.
- 사용자 검토: 업무를 선택하고 이름·내용·기한을 바꾼 뒤 승인할 수 있다.

## 2. 담당 부서 불일치

- 통화 상황: 교육 담당자에게 시스템 도입 권한이 없어 정보화 부서 또는 혁신사업단 연결이 필요하다.
- 기대 요약: 담당 권한의 한계와 신규 이해관계자 연결 필요성이 표시된다.
- 기대 영업 단계: `의사결정자 탐색`
- 기대 업무: 정보화 부서 연결, 의사결정 구조 확인, 교육·구축 제안 분리, 1페이지 자료
- 동적 업무 확인: 시나리오 1에 없는 `정보화 담당 부서 연결 요청`이 표시된다.
- 사용자 검토: 일부만 선택하고 수정·승인할 수 있다.

## 3. 현재 도입 거절

- 통화 상황: 이번 학기 예산과 운영 여력이 없으나 겨울방학 또는 다음 연도 가능성은 남아 있다.
- 기대 요약: 현재 거절과 장기 재검토 가능성을 동시에 표시한다.
- 기대 영업 단계: `장기 보류`
- 기대 업무: 거절 사유 기록, 겨울방학 후보 분류, 예산 편성 시기 확인, 2시간 쇼케이스 자료
- 동적 업무 확인: 앞선 시나리오에 없는 `현재 거절 사유 기록`이 표시된다.
- 사용자 검토: 보류 또는 승인하고 승인 업무만 저장할 수 있다.

## 공통 통과 조건

시나리오 변경 시 이전 분석과 선택 목록이 초기화된다. 분석 중 버튼은 비활성화된다. 빈 녹취록은 분석할 수 없다. 저장 후 `ax-sales-navigator:approved-actions` 키에는 승인 상태의 업무만 존재한다.
